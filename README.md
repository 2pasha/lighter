# ⚡ Світло Бот — Вінницяобленерго (ГПВ)

Багатокористувацький Telegram-бот українською мовою для моніторингу графіків погодинних відключень електроенергії (ГПВ) у Вінницькій області (**АТ «Вінницяобленерго»**).

## 🔔 Можливості бота

1. **Сповіщення про графік на завтра** — щойно обленерго публікує розклад на наступну добу, бот надсилає вам візуальну таблицю (у стилі `@pat_voe_bot`) та детальний текстовий розклад.
2. **Сповіщення про зміни в графіку** — якщо протягом дня графік скориговано (додано або скасовано слоти відключень), бот миттєво надсилає оновлення з підрахунком різниці (`+` / `-` годин).
3. **Попередження за 15 хвилин до вимкнення світла** — працює як для підтверджених відключень (🔴 / сині клітинки), так і для запланованих/можливих відключень (🟡 / жовті клітинки), із зазначенням тривалості та часу очікуваного відновлення.
4. **Повідомлення за 15 хвилин до відновлення світла** — нагадує, що за 15 хвилин електропостачання має відновитися, та показує, до котрої години світло буде наявне.
5. **Кілька локацій на користувача** — додавайте `🏠 Дім`, `🏢 Робота`, `👨‍👩‍👧 Батьки` тощо (пошук за точною адресою через базу `voe.com.ua` або прямий вибір черги `1.1` – `6.2`).
6. **Тихі години (Не турбувати)** — автоматичне вимкнення 15-хвилинних попереджень уночі (за замовчуванням `00:00–07:00`, можна змінити у меню `⚙️ Налаштування`).
7. **Розпізнавання картинок із `@pat_voe_bot`** — ви можете просто переслати або надіслати боту картинку графіка з офіційного бота, і вбудований парсер піксельної сітки автоматично розпізнає всі 24 годинні (та 48 півгодинних) слотів.

## 🏗 Архітектура джерел даних (3 рівні надійності)

Оскільки основний піддомен `disconnection.voe.com.ua` захищений Cloudflare challenge, бот використовує комбінований підхід:
1. **Вебформа `https://www.voe.com.ua/disconnection/detailed`** — прямий пошук за адресою (місто $\rightarrow$ вулиця $\rightarrow$ будинок через офіційні autocomplete-ендпоїнти `read_city`, `read_street`, `read_house`), автоматичне визначення черги ГПВ та парсинг таблиці.
2. **GitHub JSON Mirror (`vn-progr/gpv-voe-vinnytsia`)** — швидке отримання графіків одразу для всіх 12 підчерг (`1.1` .. `6.2`) на сьогодні та завтра без навантаження на сайт обленерго.
3. **Fallback через офіційний бот `@pat_voe_bot` + парсер зображень** — розпізнавання офіційних PNG-таблиць (блакитні клітинки `RGB(1, 176, 241)` = відключення, жовті `RGB(255, 192, 0)` = заплановане відключення, білі = світло є).

## 🚀 Швидкий старт (Локально)

### 1. Створіть бота в Telegram
1. Відкрийте [@BotFather](https://t.me/BotFather) у Telegram і надішліть команду `/newbot`.
2. Скопіюйте отриманий `BOT_TOKEN`.

### 2. Налаштуйте змінні середовища
```bash
cp .env.example .env
```
Відкрийте файл `.env` і вставте ваш токен у поле `BOT_TOKEN=...`.

### 3. Встановіть залежності та запустіть
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python -m app.main
```

## 🐳 Запуск через Docker / Хмарні платформи (Railway, Render, Fly.io)

У проєкт вже додані конфігураційні файли [`Dockerfile`](Dockerfile), [`docker-compose.yml`](docker-compose.yml), [`railway.json`](railway.json) та [`render.yaml`](render.yaml). Бот також запускає вбудований легковаговий HTTP healthcheck-сервер на порту `PORT` (за замовчуванням `8080`), щоб хмарні платформи бачили, що сервіс активний.

### Запуск через Docker Compose:
```bash
docker compose up -d --build
```

### Деплой на Railway або Render:
1. Завантажте репозиторій на GitHub.
2. Створіть новий проєкт у **Railway** або **Render** і підключіть ваш репозиторій.
3. Додайте змінну середовища `BOT_TOKEN` у налаштуваннях сервісу.
4. Сервіс автоматично збере Docker-образ і запуститься у режимі 24/7.
